# Supplier and software sources

The project license covers original VOLLEY material. Supplier documents retain their own rights. No express redistribution license was established for the Eaton, Infineon, Texas Instruments or feeder catalog PDFs, so this package distributes their source identities and URLs instead of the PDFs or full-text extractions. Public availability alone is not treated as permission. Reference values remain catalog data, without installed or space qualification.
