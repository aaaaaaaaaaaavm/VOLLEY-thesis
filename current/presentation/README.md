No individual research-contribution attribution is inferred from speaking roles.

Frozen manifest/provenance record the original export. The distributed builder changes only asset and external-template path handling so it can run in this standalone tree. Its current source hash is in the package manifest. Original command paths in frozen provenance describe the past run and are not runtime dependencies.
