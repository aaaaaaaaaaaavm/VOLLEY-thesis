# Historical engineering records

These files preserve earlier analyses, configuration decisions and rejected branches of the VOLLEY design study. They are retained for traceability. Their original directory structure differed from this standalone thesis repository; links to included local records have been corrected. Where a referenced historical artifact is absent, the source path is shown as text rather than presented as a working local link.

The current Gen5 thesis claims, figures and limits are controlled by the final-year report, manuscript, P-series validation sheets and CAD audit in this repository. Historical A-series and design-decision records do not by themselves establish a current hardware rating or provider acceptance.
